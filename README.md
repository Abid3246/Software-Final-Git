# School Management System

## Project Overview

The School Management System (SMS) is a Software Engineering project designed to automate and simplify the academic and administrative activities of a school.

The system provides a centralized platform for Admin, Teacher, and Student users, with role-based access to the functions relevant to each user.

The project aims to reduce paperwork, minimize errors, improve record management, and make school-related information easier to access and manage.

## User Roles

### Admin

The Admin is responsible for managing major school operations, including:

- User Account Management
- Student Management
- Teacher Management
- Class Management
- Subject Management
- Fee Management
- Notice Management
- Report Management
- Password Management

### Teacher

The Teacher can:

- View Dashboard
- Manage Profile
- View Assigned Classes
- View Student Information
- Record Attendance
- Enter Examination Marks
- View Academic Reports
- View Notices
- Change Password

### Student

The Student can:

- View Dashboard
- Manage/View Profile
- View Attendance
- View Examination Results
- View Notices
- Change Password
